# KNU 놓치지마 E순간 — 공지·장학·공모 시제품

강원대학교 공개 [일반공지](https://www.kangwon.ac.kr/ko/bbs/504/list.do), [행사안내](https://www.kangwon.ac.kr/ko/bbs/715/list.do), [장학공지](https://www.kangwon.ac.kr/ko/bbs/721/list.do), [공모안내](https://www.kangwon.ac.kr/ko/bbs/719/list.do)의 첫 페이지를 수집해 춘천·삼척캠퍼스 공지를 보여줍니다. 제목, 대상 캠퍼스, 게시일, 원문 URL, 본문, 본문 링크, 이미지 주소와 대체 설명을 저장합니다. 이미지 공지는 원문 링크로 확인할 수 있습니다.

첫 화면에서 **강원대 학생 / 춘천 주민 / 삼척 주민**을 선택합니다. 주민은 가입·학사정보 입력 없이 선택 지역의 행사만 봅니다. 학생은 학교 공지와 선택 지역 행사를 함께 보고 `전체 소식 / 학교 공지 / 지역 행사`로 나눌 수 있습니다. 지역 행사 저장본은 [춘천시 관광포털](https://www.chuncheon.go.kr/tour/festival-event/main/)과 [삼척관광문화재단 행사 달력](https://www.stcf.or.kr/01298/01402.web)의 공개 일정에서 가져왔습니다.

## 실행

Node.js 20 이상과 pnpm이 필요합니다.

```bash
pnpm install
pnpm run collect
pnpm test
pnpm build
```

다시 수집하면 글 고유번호를 기준으로 새 글을 추가합니다. `pnpm run watch`는 실행 중 15분마다 확인합니다. 수집 결과는 `data/notices.json`과 웹용 `dist/notices.json`에 저장됩니다. 웹 화면은 `dist/index.html`입니다.

같은 실행에서 현재·다음 달의 지역 행사도 확인하고 `data/events.json`, `dist/events.json`에 저장합니다. 배포된 사이트는 방문 시 학교 목록을 서버에서 조회하고, 성공 결과를 15분 동안 보관합니다. 열린 화면도 15분마다 다시 확인합니다. 새 공지의 제목·대상 캠퍼스·게시일을 보여주며, 본문은 원문에서 확인하도록 안내합니다. 사이트에 방문자가 없을 때 15분마다 실행되는 별도 예약 작업은 없습니다.

한국관광공사 TourAPI 인증키를 서버 환경 변수 `TOUR_API_KEY`로 연결해 춘천·삼척의 남은 행사 일정을 조회합니다. 같은 키로 [춘천시 문화축제 API](https://www.data.go.kr/data/15112147/openapi.do), [공연행사 API](https://www.data.go.kr/data/15112146/openapi.do), [삼척시 전국대회 API](https://www.data.go.kr/data/15027891/fileData.do)도 조회합니다. 삼척시 전국대회 API의 최신 공개 자료는 2024년 자료이므로 현재 날짜에 유효한 건만 표시합니다. 춘천시 관광포털과 삼척관광문화재단의 행사 페이지도 서버에서 확인합니다. 각 출처 조회에 실패하면 해당 지역의 `dist/events.json` 저장본을 사용합니다. 인증키를 웹 화면이나 저장소에 넣지 않습니다. 행사 정보가 관광공사나 지역 기관에 등록·수정되는 시점이 다르므로 새 소식이 게시와 동시에 표시된다고 보장하지 않습니다.

## 한국장학재단 장학금 조회

상단 **재단 장학금** 메뉴 또는 `/#scholarships`에서 대학생 장학금을 검색합니다. 브라우저는 우리 서버의 `GET /api/scholarships`만 호출합니다. 서버는 [공식 명세](https://infuser.odcloud.kr/oas/docs?namespace=15028252/v1)의 한 시점 자료를 읽고, 전체 응답을 검증한 뒤 D1의 활성 자료를 교체합니다. 최초 조회 시 수집하며, 이후 24시간이 지나면 다음 조회에서 갱신합니다. 갱신 실패 시 마지막 정상 자료와 안내를 함께 표시합니다.

운영 환경에서는 Sites의 서버 비밀 설정에 `DATA_GO_KR_SERVICE_KEY`를 등록하고 배포합니다. 로컬 실행은 프로젝트 루트에서 아래 순서를 따릅니다.

```powershell
pnpm install
Copy-Item .env.example .dev.vars
# .dev.vars에 DATA_GO_KR_SERVICE_KEY 값을 입력합니다.
pnpm build
pnpm dlx wrangler@4 d1 migrations apply knu-local --local --config wrangler.local.jsonc
pnpm dlx wrangler@4 dev --local --config wrangler.local.jsonc
```

`DATA_GO_KR_SCHOLARSHIP_PATH`를 비워 두면 2026-10-14 자료를 사용합니다. 이후 공개본으로 전환할 때는 위 명세의 해당 월 `/15028252/v1/uddi:…` 경로만 입력합니다. 인증키를 HTML이나 Git에 넣지 마세요. 로컬 기본 주소는 `http://localhost:8787/#scholarships`이며 단위·통합 검증은 `pnpm test`로 실행합니다.

## K-Startup 창업지원 공고

검색결과의 **창업지원** 필터와 곰두리 상담에서는 [창업진흥원 K-Startup 사업공고](https://www.data.go.kr/data/15125364/openapi.do)를 조회합니다. `/#startup`은 강원·전국 대상 창업지원 공고를 열고, 지원지역을 **모든 지역**으로 바꿀 수 있습니다. 서버의 `GET /api/startups`는 기존 `DATA_GO_KR_SERVICE_KEY`로 모집 중(`Y`)인 공고를 받아 전체 페이지 검증 후 D1에 저장합니다. 새 서버에는 위의 D1 마이그레이션을 모두 적용하고, 공공데이터포털에서 해당 서비스 활용 승인을 받으세요. 15분 후 다음 조회에서 갱신하며, 실패하면 마지막 정상 자료와 상태를 표시합니다.

## 국가장학금 통계

검색결과에서 **장학금 → 국가장학금 통계**를 열면 신청·수혜 인원(`15114806`)과 다자녀 지원금액(`15113367`)을 연도·학기별로 조회합니다. 두 자료는 현재 신청 공고가 아닌 2025-12-31 기준 집계입니다. `GET /api/scholarship-statistics?type=people|family`는 기존 서버 환경변수 `DATA_GO_KR_SERVICE_KEY`를 사용하며, 두 API 모두 활용 승인이 필요합니다. 최신 공개 스냅샷 한 개씩만 순차 수집하고 D1에 24시간 캐시하며, 전체 수집 실패 시 마지막 정상 자료를 유지합니다. `0009_scholarship_statistics` 마이그레이션을 포함해 적용하세요.

곰두리에서 “2025년 1학기 국가장학금 수혜 인원 통계 알려줘”처럼 질문할 수 있습니다. 답변은 서버가 다시 확인한 원문 집계 행에 근거합니다. 학기별 인원을 연간 고유 인원으로 합산하지 않으며, 다자녀 총수혜금액은 명세의 화폐 단위가 확인되지 않아 원문 수치로 표시합니다. 기준일과 실제 동기화 시각은 각각 표시됩니다.

## 학생 조건 기반 추천

학생은 사이트에서 아이디와 비밀번호로 실제 계정을 만든 뒤 **내 정보 설정**에서 캠퍼스, 학적 상태, 학위 과정, 학년·현재 학기·이수 학기 수, 직전·전체 평균평점, 직전·총 이수학점, 학자금 지원구간 등을 입력합니다. 값은 서버의 계정에 저장되어 다른 기기에서 로그인해도 불러올 수 있습니다. 비밀번호는 소금값을 사용한 PBKDF2 해시로 보관하고, 로그인 세션은 보안 쿠키로 관리합니다. 주민 화면은 가입 없이 이용할 수 있습니다.

`dist/match.mjs`는 장학·공모 본문에 **명시된 일부 조건**을 추출해 입력값과 비교합니다. 캠퍼스, 재학 여부, 평균평점, 학점, 이수 학기 수, 학년·학기, 지원구간을 비교하고 `추천 후보 / 추가 확인 / 조건 불일치`로 표시합니다. 결과 상세에는 일치·불일치·미입력 항목과 추출한 근거 문장을 보여줍니다. 추천 후보는 자격 확정이 아닙니다. 첨부파일, 복합 조건, 마감일을 포함한 최종 자격은 공지 원문에서 확인해야 합니다.

학교 학사정보 자동 연동, 이메일 인증·비밀번호 복구, 이미지 OCR, AI 요약, 지역 혜택 수집, 서버의 자동 수집 예약은 구현하지 않았습니다. 공개 사이트의 HTML 구조가 바뀌면 수집 선택자를 조정해야 합니다.

## 곰두리 AI 상담

`/#gomduri`에서 채팅을 엽니다. 기기에서 한국어 문장과 현재 공고를 비교해 관련 공고를 찾고, “1번과 2번 신청 조건이 어떻게 달라?” 같은 후속 질문에서 방금 보여준 공고 번호를 이어서 사용합니다. 모집 중인 한국장학재단 장학금은 기존 D1 캐시의 `/api/scholarships/chat`에서도 읽습니다.

Gemini 답변을 쓰려면 서버의 비밀 환경변수 `GEMINI_API_KEY`를 설정하고 D1 마이그레이션을 적용하세요. 채팅의 Gemini 옵션을 켜면 서버는 현재 질문과 직전 AI 답변, 최근에 본 공고 제목·지역을 바탕으로 추가 질문, 검색 또는 기존 앱 작업 중 하나를 고릅니다. 검색한 경우 서버가 찾아낸 공개 공고를 바탕으로 답해요. AI 연결이 안 되면 기기 검색으로 전환합니다. 저장된 계정·학사 프로필과 이전 대화 전문은 보내지 않습니다. 서버는 인용문이 해당 공고에 실제로 있는지 대조합니다. 검증 실패, 통신 오류, 이용 한도 초과 시에는 검색 결과를 표시합니다. 서버 호출 한도는 IP당 시간당 20회, 사이트 전체 하루 300회입니다. HTML을 내려받아 열어도 Gemini 답변과 최신 자료 조회에는 인터넷 연결이 필요합니다.

브라우저 검색 모델은 minishlab의 MIT 라이선스 `potion-multilingual-128M`에서 한국어 위주로 줄인 모델입니다. 모델 출처·라이선스와 재생성 스크립트는 `src/ai/`에 있습니다. 앱 실행과 빌드에는 모델 다운로드가 필요하지 않습니다.

## 고용24 일학습병행

`/#training`과 검색결과의 ‘일학습병행’에서 강원 훈련과정을 봅니다. 기본은 춘천·삼척이며 훈련지역에서 강원 전체로 넓힐 수 있습니다. 기관명에 들어 있는 지역과 훈련 장소를 구분합니다. 훈련 시작일로 과거 365일부터 향후 180일까지 조회하고 종료된 과정은 제외합니다. 훈련 시작·종료일은 접수기간과 구분해 표시합니다.

서버의 `WORK24_TRAINING_API_KEY`에 고용24의 해당 서비스 승인키를 등록하고 D1 마이그레이션을 적용합니다. `GET /api/work24`는 강원 지역의 공식 목록 API 두 기간을 페이지 끝까지 읽고 성공한 자료를 D1에 교체합니다. 방문 중에는 15분 간격으로 다시 확인하며 실패 시 마지막 정상 자료와 안내를 제공합니다. 공식 명세는 https://www.work24.go.kr/cm/e/a/0110/selectOpenApiSvcInfo.do?fullApiSvcId=000000000000000000000000000017 입니다.
